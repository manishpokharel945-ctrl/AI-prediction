# AI Student Result Prediction

This is a simple AI prediction project built using Python. It predicts whether a student is likely to pass or fail based on study hours and attendance percentage.

## Features

- Uses student study hours and attendance data
- Trains a simple machine learning model
- Predicts student result as Pass or Fail
- Uses a CSV dataset
- Beginner-friendly AI/ML project

## Technologies Used

- Python
- Pandas
- Scikit-learn

## Files Included

- AI prediction.py
- student_data.csv
- README.md

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install required libraries:

pip install pandas scikit-learn

4. Run the Python file:

python "AI prediction.py"

5. Enter study hours and attendance percentage.
6. The system will show the prediction result.

## Example

Enter study hours per day: 6  
Enter attendance percentage: 80  

Prediction Result:  
The student is likely to: Pass
